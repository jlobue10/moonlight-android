PyroWave codec tree (pyrowave/), copied from Vibepollo's third-party/pyrowave/pyrowave,
which is the output of its vendor-pyrowave.ps1 (pruned Granite subset the C API needs)
with the patches in pyrowave-patches/ applied. Using the host's exact tree guarantees
the bitstream matches: PyroWave carries no version field, the host advertises the
commit as `a=x-ss-pyrowave.bitstream:186f0393` and the client warns on a mismatch.

pyrowave:        186f0393b77f7755953b5ecde994bb1cec2e4155 (https://github.com/Themaister/pyrowave, MIT)
Granite:         b6cffd5ce81f540f0855e6778428483e14763d9b (https://github.com/Themaister/Granite, MIT)
volk:            47cddf7ed97b94118a08aacb548a411188e016cc (MIT)
vulkan-headers:  6802bb4733b63ed5efd3adb308a6c885ef180ea1 (Apache-2.0)
Patches (Vibepollo): 0001-encoder-buffer-pool, 0002-payload-data-444-sizing,
                     0003-decoder-reject-short-block (no bitstream changes).

The Android renderer (pyrowave_renderer.cpp, shaders/, shaders_spv.h) and
PyroWaveDecoderRenderer.java come from joemossjr16/artemis-android-pyrowave
(branch pyrowave, GPL-3.0 like this app), adapted here.

To move to a newer codec revision: update the host first, re-vendor from its tree,
and keep the two in lockstep.
